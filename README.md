## How to run this project

This is a static website and can be opened directly in a modern web browser.

### Prerequisites

- A modern web browser such as Chrome, Edge or Firefox
- Git, if you want to clone and manage the project repository
- Internet access is recommended because the page references Bootstrap Icons through a CDN

### Installation

Clone the repository:

```bash
git clone https://github.com/leonix-code/Portfolio.git
cd Portfolio
```

Open the project folder and launch `index.html` in the browser, or serve it locally with:

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in your browser.
